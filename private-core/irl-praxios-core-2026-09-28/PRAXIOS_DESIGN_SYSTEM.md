# PRAXIOS Design System v0.1

## Dirección

PRAXIOS utiliza una estética de sala de control técnica, sobria y legible.

El objetivo visual es transmitir estado, trazabilidad, control, evidencia y autoridad.

## Color semántico

- Human Authority / Accent: #D7ED00
- Execution / Running: #56D5FF
- PASS: #63D89B
- REVIEW: #FFBE63
- BLOCK: #FF7676
- Hypothesis: #B79CFF

## Superficies

- Background 0: #05090D
- Background 1: #091018
- Surface: #0C151E
- Raised: #101C28
- Line: #203244

## Tipografía

System UI para interfaz y familia monoespaciada del sistema para ledger, identificadores y estados técnicos.

## Principios

1. State first.
2. Evidence visible.
3. Human authority explicit.
4. Calm information density.
5. Text + color for status.
6. Provider-agnostic model representation.
7. One canonical state, multiple views.

## Componentes

mode switch, node, edge, gate row, claim card, evidence card, human checkpoint, ledger row, model slot, status badge, command queue y decision option.
